# 服装管理系统

## 项目介绍
这是一个用C语言编写的小型服装管理系统，实现了服装信息的录入、增删改查、购物车功能以及数据统计分析等功能。

## 功能特点
1. **服装信息管理**：录入、增删改查服装信息
2. **购物车功能**：添加商品到购物车、删除商品、结算
3. **数据分析**：
   - 品牌收入分析，找出最赚钱的品类
   - K-means聚类分析，统计不同类别的毛利率
   - 品牌、品类、价格对销量的影响分析

## 项目文件
- `main.c`：主程序文件，包含所有功能实现
- `init_data.c`：数据初始化程序，用于生成测试数据
- `README.md`：项目说明文档

## 编译和运行

### 方法一：使用GCC编译器
1. 确保已安装GCC编译器（如MinGW或Cygwin）
2. 打开命令行终端，进入项目目录
3. 编译初始化程序：
   ```
   gcc -o init_data init_data.c
   ```
4. 运行初始化程序生成数据：
   ```
   ./init_data
   ```
5. 编译主程序：
   ```
   gcc -o clothing_system main.c -lm
   ```
6. 运行主程序：
   ```
   ./clothing_system
   ```

### 方法二：使用Visual Studio
1. 打开Visual Studio，创建一个新的空项目
2. 将`main.c`和`init_data.c`添加到项目中
3. 编译并运行初始化程序生成数据
4. 编译并运行主程序

## 操作说明

### 主菜单
1. 显示所有服装信息
2. 添加服装信息
3. 删除服装信息
4. 查找服装信息
5. 修改服装信息

3. 从购物车删除商品

5. 返回主菜单

## 数据分析说明

### 品牌收入分析
- 计算每个品牌中不同品类的销售收入占比
- 使用数学期望方法找出每个品牌最赚钱的品类

### K-means聚类分析
- 基于价格、销量、成本三个维度进行聚类
- 将服装分成3个类别
- 统计每个类别的毛利率

### 因素影响分析
- 分析品牌、品类、价格对销量的影响
- 提供数据支持的分析结果
