项目名称：服装销售系统
1．教学内容
本次课程设计要求用C语言编程实现一个小型的服装管理系统，每个服装的信息可以包括品牌、品类、价格、销售量、成本等（如：NIKE-短袖-198-2000-50）。通过菜单选择要操作的功能选项，具体实现任务如下：
（1）录入服装信息（录入至少30个服装，包含3个品牌，每个品牌3个品类），要求按一定格式保存到文件中；
（2）对服装信息进行增、删、查、改等操作；
（3）顾客可以把多个服装商品放进购物车中，也可以选择多个服装商品直接付款；
（4）分析每个品牌中不同品类的销售收入占比，结合销量和成本，找出每个品牌最赚钱的品类（建议采用数学期望方法）；
（5）基于价格、销量、成本这三个维度，将全部服装分成不同的类别，分别统计每个类别的毛利率（建议采用k-means方法）；
（6）基于已录入的服装信息，请自行设计任务并获得数据，基于数据，论证品牌、品类和价格这三者对销量的影响。
2．教学要求
（1）能理解项目需求，并分解成各个小任务；
（2）能运用C语言知识，设计项目的代码框架、功能实现、会员结构体；
（3）能按易到难，用C语言实现各项任务；
（4）能按实践报告内容和格式要求，编写实践报告；
（5）能按项目答辩要求，完成项目答辩相关工作。
3．重点与难点
（1）重点：服装管理系统框架设计，如何用C语言结构体对服装信息进行描述。
（2）难点：对录入的服装信息进行数据分析。
4．教学实施建议
（1）建议把服装设计为一种结构体，所有服装形成一个链表；
（2）可以适当给予学生关于各种结构体设计、项目程序框架等提示，帮助学生快速进入状态；
（3）要求每周至少全班同学检查一遍项目完成进度，针对进度慢的同学，应该给予重点帮助；
（4）老师可以根据班级同学的完成情况，适当调整任务要求。
